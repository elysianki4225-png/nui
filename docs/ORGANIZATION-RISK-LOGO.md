# 文件夹、拖动排序、风控与 Logo

## 用户文件夹与排序

- 用户的备忘录列表提供「新建文件夹」。首版为单层文件夹，最多 200 个，名称最多 80 个字符。
- 每个文件/文件夹的「整理」菜单支持移动、重命名或删除文件夹。删除文件夹会将内容移回根目录，不删除备忘录。
- PC/手机按住拖动柄约 180ms，拖到另一项上方松开，即可调整顺序。拖动柄外保留正常页面滚动；支持列表与网格、边缘自动滚动及键盘上下方向键。调整后自动切到「手动排序」，不再按日期/置顶分组；可在排序菜单切回日期或标题排序。
- 文件夹名称、文件归属、手动排序在客户端用现有账号密钥加密后保存。后端不获得这些信息的明文；文件内容仍使用原有加密与存储流程。整理索引作为加密账号元数据保存在服务端，明文上限 240KiB。
- 同一账号其他设备改过整理索引时，保存返回冲突，需刷新再操作。不会静默覆盖，也不支持离线合并。旧客户端不理解文件夹，仍可能平铺展示全部备忘录。
- 登出/锁定清除内存中的明文整理索引；拖动预览、监听器和动画帧随页面退出清理。减少动态效果设置会停用落位动画，不承诺所有设备都维持固定帧率。

## 管理员风控

管理侧栏新增「风控」，默认两个开关均关闭：

1. **启用风控检测**：对异常请求按 IP 累计；记录命中原因与浏览器基础特征摘要。
2. **自动临时封锁 IP**：检测同时开启时，10 分钟窗口内至少 20 次登录凭据失败，或至少 120 次已经触发限流的请求，封锁该 IP 15 分钟。单次普通访问、切换 IP/浏览器不会触发封锁。成功登录清除该 IP 的当前计数。

浏览器摘要来自截断后的 User-Agent、语言和浏览器自带 Client Hints，使用进程随机盐做 HMAC；不采集 Canvas、字体、硬件清单或跨站持久设备 ID，不保存这些请求头原文。摘要不是可靠身份，可伪造且重启后变化，只辅助排查，不作为单独封锁依据。

- 风控命中最多存 200 条，界面展示最近 24 小时；自动封锁最多 500 条，活动计数最多 5000 个 IP。过期封锁不执行，关闭任一开关清除自动封锁。历史日志/备份仍按现有存储保留策略管理。
- 现有「IP 封禁」属于人工规则，不受风控开关影响。
- 已登录管理员保留风控恢复接口，使用独立的管理请求限流桶，可手动解封。无有效管理会话时，误封需要等待临时封锁到期。
- 共享 NAT、VPN、校园/公司网络仍可能被误伤，建议先开启检测观察，再开启自动封锁。
- 自动风控依赖正确的反向代理真实 IP 设置，不是 DDoS 防护，也不代替 CF/WAF/服务器安全策略。

## 管理员 Logo

「主题」→「素材用途」选择「备忘录 Logo」，上传图片，在浏览器压缩/预览后确认。支持现有 JPEG、PNG、WebP、GIF 流程，不接受 SVG。静态 Logo 压缩到最长边 512px；可删除素材恢复默认。

Logo 跟随管理员选择的全站存储方式：本地或 Telegram。素材复用已有加密存储、迁移、清理与 VPS 代理读取流程；浏览器不使用 Telegram 原始文件链接。Logo 属于公开品牌素材，不是用户私密内容。用户端导航/登录标识及页面 favicon 使用新 Logo，其他设备重新打开后生效。原生浏览器安装应用时缓存的图标不保证立即更新。
