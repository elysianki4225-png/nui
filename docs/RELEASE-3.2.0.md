# 备忘录 3.2.0

## 文件工作区

自有品牌的 Drive 风格布局：桌面宽侧栏、新建入口、圆角工作区与清晰文件行；手机保留抽屉、触控整理按钮和响应式列表/网格。继续使用虚拟列表、加密索引和 3.1.1 的紧凑拖动预览。

PC 右键、Shift+F10 / ContextMenu 键和触屏「整理」使用同一组真实操作：打开、下载、加密重命名、置顶、移动到已有文件夹、选择、删除。菜单支持方向键、Home/End、Enter/空格、Escape；文件夹删除明确保留内容。删除是永久删除，没有回收站，也未新增共享或协作。

## 素材进度

背景、桌宠、Logo 分别显示本地压缩/抠图、XHR 实际上传字节进度，以及传输完毕后的存储等待状态。收到服务端成功响应才显示保存成功，不以假计时器模拟百分比。取消上传或离开页面会中止客户端工作；如果服务器已经收齐数据，仍可能继续保存，取消提示会要求检查素材列表。

## 维护安全与安装要求

管理端「系统维护」：

1. 检查本仓库 main 的版本和提交 SHA；确认后的目标有效期 5 分钟。
2. 更新、服务重启、整机重启均需重新输入管理员密码；整机重启还必须输入“重启服务器”。错误认证限流。
3. 应用只能提交固定动作，由安装器部署的 root-owned systemd path/service/helper 执行。不运行浏览器提供的 shell、路径或下载地址，不授予应用用户 sudo，不把网页服务改为 root。
4. helper 再次核对 main SHA，固定 SHA 下载，限制文件大小/数量、拒绝路径穿越和链接、检查结构与语法、拒绝降级。更新前备份程序和配置，停止应用后备份元数据；安装后检查后端健康，正常安装错误或健康失败尝试恢复旧程序与元数据。
5. 拒绝并行维护、存储迁移或其他进行中的写入。维护期间业务写入暂停；管理查询、登录、任务状态仍可访问。请求与观察到的结果进入审计，后台有阶段状态，不用 HTTP 断开推断成功。
6. 请求文件限制读取长度，拒绝符号链接/非普通文件；root 私有凭据目录记录任务 ID 防重放。密码及计算器原始暗号不写入任务文件或审计。

旧安装器可能只更新程序而没有执行新版安装器中的 helper 安装步骤。页面显示“维护服务未安装”时，在 SSH 执行：

```sh
sudo bash /opt/nui-memo/install.sh --update -y
```

需要正式合并后的 main 和官方 systemd 安装；开发模式、其他容器/托管安装没有维护 helper，按钮禁用。不能用旧页面直接启动尚未安装的特权服务。

故障排查：

```sh
sudo journalctl -u nui-memo-maintenance -n 100 --no-pager
sudo systemctl status nui-memo-maintenance.path nui-memo
```

- 更新恢复副本位于 `/var/backups/nui-memo/<任务 ID>/`，成功更新后最多保留最近三份。包含程序、配置和元数据，不是媒体对象完整备份；请另行备份整个数据目录及外部存储。
- root 任务防重放记录在 `/var/lib/nui-maintenance`，超过一天的记录在后续任务时清理。
- 整机重启只报告“已提交系统请求”，不宣称其他业务均已恢复。重启会影响该主机所有服务。
- 突然断电、进程被强杀、磁盘故障、运行时/系统依赖变更等不保证自动回滚；必要时通过 SSH 检查备份并手动恢复。此机制不替代独立灾备。
- 更新下载与版本查询需要 GitHub 可达；没有自动配置 DNS 或改变域名、CDN、证书及现有端口策略。

## 计算器伪装

开启后，未获入口通行凭证的访客只看到功能正常的计算器。输入独立的 6–12 位数字暗号再按等号，会获得 15 分钟 HttpOnly / SameSite=Strict 入口凭证，然后显示普通管理员登录。暗号建议至少 8 位；服务端保存哈希并限流。修改暗号或重启后旧入口凭证失效，退出登录会清除凭证。

已登录的管理员可以直接管理；暗号不替代管理员账号、密码或启用的人机验证。后端同时限制直接访问登录接口，非单纯隐藏 HTML。源码、资源和接口仍可能暴露产品身份，不应视为隐身或独立安全边界。

忘记暗号：SSH 运行 `n-ui`，重置管理员凭据；该操作关闭伪装并使原管理员会话失效。

## 验证

- 服务端真实 HTTP：暗号设置、哈希持久化、入口限制、CSRF、限流、退出、仍需登录与密码重新认证。
- helper 隔离测试：固定命令、非法/过期/重复任务、链接攻击、并发任务、实际文件备份与安装/健康失败恢复。所有系统命令使用注入的模拟执行器，不重启测试机。
- 浏览器：右键/键盘菜单、加密重命名持久化、真实素材上传、计算器解锁与服务端保护；320/360/768/1440px 响应式检查以及原有拖动、端到端加密、CAPTCHA 和入口验证回归。
