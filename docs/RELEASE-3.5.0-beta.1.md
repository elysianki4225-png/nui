# 备忘录 3.5.0-beta.1

这是 **预发布测试版**，包含此前 3.1.1、3.2.0、3.3.0 分支改动，不替换正式稳定版、不自动部署或重启生产服务器。

## 本轮审查与修复

审查重点：鉴权/CSRF/限流、管理员维护与安装脚本、更新失败恢复、入口伪装、异步外观加载、素材和音频上传、桌宠生命周期与端到端加密/存储链路；同时执行仓库完整发布验证。不是对所有代码“绝对无缺陷”的认证。

- 更新检查和 root helper 支持 `x.y.z-beta.N`，正确比较 Beta 序号与同版本正式版，拒绝非规范版本及降级。
- 元数据备份使用不跟随符号链接的文件描述符读取，拒绝 FIFO/非普通文件，限制单文件最多 512MiB，以有界缓冲复制；超限会停止更新并尝试恢复服务，不截断数据。
- 回滚采用原子替换，不向应用可修改的符号链接目标写入；恢复应用用户所有权和 0600 权限。仅完整完成元数据备份后才恢复元数据，移除更新前不存在的新日志，避免旧快照重放新日志。
- 维护状态读取拒绝符号链接/FIFO，读取长度有界，避免同步读取特殊文件阻塞服务。
- 旧外观请求不再覆盖更新后的外观或计算器入口清理结果。
- 管理入口状态请求失败时不显示登录表单或管理壳，只显示重试；重复启动请求忽略过期响应。

## 保留功能

手机新建面板、PC 右键/键盘菜单、端到端加密重命名和文件夹整理；真实素材上传进度；密码二次认证的系统维护；计算器伪装；可拖动且不出屏的桌宠；短音频处理/试听/上传；用户单独关闭管理员背景、桌宠、声音。

音频仍为最大 30MB/60 秒输入，转为单声道 16kHz PCM WAV，不是高保真长音乐播放器。用户端默认静音，主动开启后点击桌宠播放/停止。

## 发布验证

- `scripts/check-release.sh`：前后端模块语法、HTTP 权限和安全、存储/迁移/故障恢复、域名/CDN/NAT/CAPTCHA、安装脚本、UI/资源生命周期、音频 Worker/处理及依赖审计。
- 新增 Beta 版本排序、元数据目标链接攻击、源链接/FIFO 拒绝、缺失文件和状态读取用例。
- 新增外观异步竞态、管理员状态失败关闭与重试用例；保留 Chromium 的真实加密/上传/音频、鼠标/触屏拖动和多尺寸布局验证。
- root helper 测试只使用临时目录和模拟系统命令；没有实际重启测试机或生产服务器。CI 另执行真实 Caddy 配置验证。

## 安装与更新通道

GitHub tag：`v3.5.0-beta.1`。预发布包来自经过验证的工作分支提交，不需要先合并 main。

已有官方安装，先备份，再通过 SSH 明确选择 Beta：

```sh
sudo env NUI_REF=v3.5.0-beta.1 bash /opt/nui-memo/install.sh --update -y
```

如果原安装器只更新了程序、页面仍提示维护服务未安装，再使用同一命令运行新版安装器。不要漏掉 `NUI_REF`，否则仍下载 main。面板更新继续固定 main，拒绝比当前 Beta 更旧的版本；不会擅自改为订阅测试版本。

## 仍需注意

- 自动恢复不替代独立备份，断电、强制终止、磁盘或系统依赖故障仍可能需要 SSH 手动恢复。
- 本地 HTTP/模拟服务商测试不证明实际 VPS 网络、Telegram 服务或 CAPTCHA 服务商配置一定正常；需在部署环境验收。
- 未新增分享、协作、回收站；删除仍是永久删除。计算器伪装不等于隐藏产品身份或替代认证。
- 用户偏好与桌宠位置保存在当前浏览器，不跨设备同步。
