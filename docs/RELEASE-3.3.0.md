# 备忘录 3.3.0

- 手机右下角“新建”：网盘式底部操作面板，创建文件夹 / 上传文件 / 新建文字；上传文件直接调用系统文件选择器并支持多选。桌面新建使用相同菜单。修复文件编辑器切换模式或通过 Escape/遮罩关闭时的粘贴监听器清理。
- 桌宠：鼠标、触屏拖动，Pointer Capture，屏幕边界限制、旋转/窗口变化重新布局、本浏览器记住位置；拖动不触发声音。切换外观及移除桌宠清理监听器、停止音频。
- 管理员主题页新增桌宠音乐 / 音效的本机处理、试听、真实上传进度、取消及删除；素材继续使用统一存储/迁移链路。
- 音频限制：原文件最大 30MB、时长不超过 60 秒；浏览器解码支持的 MP3/WAV 等，统一降采样到单声道 16kHz、16-bit PCM WAV，输出最多 1,920,044 字节。已有高压缩编码转换后可能变大；面向短音效/音乐片段，不是高保真长音乐播放器。超限明确拒绝，用户先裁剪，不静默截断。
- 服务端只接收规范的转换后 WAV，校验采样率、声道、位深、时长上限、块及文件长度；普通用户不能上传公共音频，不接受伪装的图片、脚本或附加数据。
- 用户设置：“显示管理员背景”“显示管理员桌宠”“桌宠声音”，相互独立，保存于当前浏览器，不是跨设备同步，不修改管理员配置。背景/桌宠默认显示，声音默认关闭；开启声音后点击桌宠播放 / 停止，不自动播放。切到后台暂停声音，重新回到页面不自动继续。
- 伪装计算器入口继续清理管理员桌宠和声音，不显示主题推送。

测试覆盖：真实 Chromium 中 WAV 降采样、试听素材生成、上传与回读；默认静音、点击播放/停止、拖动无声音；鼠标/触屏与 320/360/768/1440px 边界；用户开关持久化和手机新建菜单/文件选择器。服务端回归涵盖音频权限、格式校验、重启持久化、删除，并继续执行原有完整发布测试。

未自动部署、重启生产服务器或更改域名/DNS。3.2.0 的维护 helper 和旧安装升级注意事项仍适用。
