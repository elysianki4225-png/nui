# 3.0.0：代码复查与稳定性修复

本版复查认证与权限、输入边界、密文索引、存储清理/迁移、域名/NAT、导出前端、安装升级，以及管理端/用户端交互。延续现有加密协议和数据结构，不要求重新注册或迁移用户密钥。

## 修复

- **分页一致性**：统一相同创建时间的 ID 排序，避免重建索引/重启后重复或漏页；重建索引改为分组后排序，减少逐条插入开销。拒绝非法分页游标。
- **导出安全**：嵌入配置时转义脚本结束边界及 Unicode 换行符，并使用替换回调避免 `$&` 等被当成替换指令。拒绝带凭据、查询参数或片段的 API 地址。
- **请求健壮性**：JSON 接口拒绝 null、数组和标量；忽略单个损坏 Cookie，避免解码异常导致服务器错误；Cookie 字典无原型。
- **上传清理**：过期未完成上传的对象引用先进入持久化清理队列，再删除备忘录元数据；可从管理员存储页清理，不再直接遗失引用。
- **验证配置竞态**：人机验证在等待期间发生配置版本变化时要求重新验证；严格校验提供商自身属性，结束时释放请求资源。
- **管理员恢复入口**：存储迁移期间允许风控配置/解封和人机验证配置操作，保留原有管理员认证、CSRF 与写入计数；其他非必要写入继续只读。
- **诊断准确性**：HTTP 4xx、HTML 挑战页不再被视为备忘录健康检查成功；响应大小受限，计时器覆盖响应体读取，失败路径释放连接；CF Token 校验不回显上游详情。
- **域名界面**：步骤编号按显示顺序排列；NAT 开启时只保留一套内部端口输入，明确 CF 回源规则应使用公网映射端口。
- **风控界面**：风控在前、人机验证在后；禁用重复提交，避免多个解封响应重复渲染；离开页面后不再重新加载旧页面。风控关闭时禁用自动封锁子选项。
- **文件夹交互**：取消拖动不再吞掉后续点击；捕获已失效指针时安全退出；长文件夹路径可换行；切换显示排序后拖动以当前可见顺序为准。

## 验证

`bash scripts/check-release.sh` 运行语法、后端/API、存储安全、双域名/证书、回滚、NAT、安装/升级、权限和依赖审计。

设置以下环境变量后包含完整 UI、图像处理与真实 Chromium 回归（CI 已启用）：

- `NUI_JSDOM_MODULE`：jsdom 模块路径
- `NUI_CANVAS_MODULE`：@napi-rs/canvas 模块路径
- `NUI_BROWSER_DEPS`：安装 playwright-core 与 @sparticuz/chromium 的 npm 前缀

新增回归涵盖重启分页、清理队列持久化、JSON/Cookie 异常输入、配置注入、迁移恢复入口、验证配置变化、诊断假阳性和响应边界、取消拖动与排序冲突。浏览器覆盖 12 个管理页面、320–1440px 视口、长 IPv6/日志、加密读写、记住登录、文件夹、鼠标/触摸排序及 CAPTCHA 弹窗清理。

## 更新提醒与边界

- 管理员通过现有更新流程升级；旧导出的单文件不会自动更新，请升级后重新导出并替换。
- 本次推送本身不等于合并 main 或部署到 VPS。
- Telegram、Cloudflare Token、人机验证 SDK/验证服务相关测试包含本地模拟，不代表持有真实凭据的端到端验收。NAT 公网映射、DNS、真实证书信任链及外部网络可达性仍需部署环境验证。
- 无法保证不存在未发现问题。端到端加密仍依赖可信前端；启用第三方 CAPTCHA 时应评估其脚本与隐私信任边界，详见 [NAT / 人机验证](NAT-CAPTCHA.md)。
