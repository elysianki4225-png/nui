# 访问加速：优选 IP / 优选域名

入口：管理员「域名」页 → 折叠的「访问加速」。默认关闭，普通用户无配置或探测权限。

## 定位与接入步骤

这是**手动 DNS 方案助手**，不是代理、自动测速选点或自动故障切换服务。它不修改 DNS、Caddy、证书、域名配置，也不重启服务；不抓取网上 IP 列表，不接受 CDN API Token。

1. 先将网站正确接入 Cloudflare 或第三方 CDN，并确认当前网址、证书和源站回源正常。直连模式不能启用优选方案。521 等回源故障不能靠优选修复。
2. 使用可信来源的候选 IP 或优选服务域名。IP 最多 8 个（支持 IPv4/IPv6），Cloudflare 模式仅接受配置中的官方 CF 网段。
3. 勾选启用方案，运行「检测候选兼容性」。检测使用**已经应用的网站域名**，不使用上方尚未保存的域名草稿。
4. 保存后生成 A/AAAA 或 CNAME 记录指引。此时实际访问完全不变。
5. 备份原 DNS 记录、确认 SSH 可用，再到 DNS/CDN 控制台按其官方规则手动设置。用户网址仍是原网站域名，不能换成裸 IP。
6. 在用户实际网络中验证效果；故障时恢复原 DNS 记录。关闭此处方案只关闭/保存助手，不会撤销已手动改动的 DNS。

## 接入前必须核对

- **共用管理域名**：如果用户端与管理端共用域名，手动改该域名 DNS 也影响管理入口。应保留 SSH 或先准备独立管理入口，本功能不会自动创建备用域名。
- **CDN 绑定与证书**：IP 能连通不代表该网站已获 CDN 授权。优选域名可能需要 CDN 自定义主机名、SaaS/合作接入等能力，不能保证所有套餐支持。
- **代理状态**：橙云 CNAME 可能仍由 CF 决定实际边缘节点，并不保证使用你填写的 IP。是否启用代理、根域 CNAME/扁平化均依照厂商支持方式，不盲目关闭或开启代理。
- **DNS 冲突**：同名 CNAME 不能和 A/AAAA 并存，根域可能还有 MX/TXT 等记录。不要误删其他业务记录。指引展示完整记录名，服务商若要求前缀应按当前 Zone 填写。
- **多个 IP**只是轮询，坏节点不会被本功能自动剔除。
- 第三方优选域名可随时改变解析，配置者必须信任其运营者。不得提供账号密钥给第三方服务。
- 改变网站域名或 CDN 后，旧方案会显示过期提示并隐藏 DNS 指引；重新核对、检测及保存后再使用。

## 检测范围及安全限制

- 按候选地址连接 HTTPS 443，固定使用网站原域名作为 Host/SNI，执行系统 CA 与证书域名验证，请求 `/api/health`。
- 只有 HTTPS 成功、HTTP 200 且返回预期健康接口形状才标记通过。挑战页、重定向、证书错误均不算通过；不跟随重定向，不带 Cookie/Authorization。
- **不证明节点所有权，也不证明为预期的同一后端**。健康响应是基础兼容性信号，不是安全认证。
- 显示的耗时是 VPS 到候选节点的单次连接/响应耗时，**不是国内用户测速**，不做速度排名或自动切换。
- 阻止内网、环回、链路本地、共享地址、文档保留、IPv4 映射和 IPv6 转换等地址。候选域名任一解析地址不安全时拒绝整个探测。
- DNS 最多 4 秒、最多 16 个地址；已校验 IP 直接连接，避免二次 DNS 解析/重绑定。CF 模式对所有解析结果检查 CF 网段。
- 全局同一时间一个诊断任务、任务内最多 2 个连接；每地址绝对 6 秒截止，响应体上限 16KiB；每来源每小时最多 20 次检测。
- 页面离开取消 HTTP 请求，并在服务端取消 DNS/连接和后续队列。超时或失败会释放 socket、监听器及计时器。
- 数据保存仅写入独立 `settings.acceleration` 记录，遵循已有存储迁移只读锁。

## 验证

`test/acceleration.mjs`：公网/IP/CNAME 格式、保留地址/转换地址拒绝、Cloudflare 网段、混合 DNS 拒绝、CNAME 循环、并发上限、Host/SNI/IP 固定、TLS 校验参数/失败处理、不跟随跳转、响应上限、取消与绝对超时、匿名/普通用户鉴权、默认关闭、持久化、迁移只读和 config 字节不变、域名变化使指引过期。

`test/acceleration-ui.cjs`：默认折叠关闭、共享管理域名警告、显式保存、诊断结果、输入变化清空旧诊断、销毁页面取消请求。

`test/browser-release.mjs`：真实 Chromium 中检查新增表单默认关闭、拒绝内网地址、四种视口无横向溢出，并继续检查既有 11 个管理页、GIF、用户加密解密和记住登录等主链路。

实际运营商线路速度、真实 CF/第三方套餐兼容性、DNS 全球传播需在部署网络验证。没有自动更改入口的行为，也不把测试通过等同于绝无缺陷。
